A simple Parking Application Form built with HTML and CSS only. This project allows users to book parking slots. All data is stored in localStorage for persistence.


---

🚀 Features

📋 Parking booking form with validation (name, contact, vehicle number, slot, entry/exit datetime).

🚗 Supports multiple vehicle types (Car, Bike, Van) with different hourly rates.

💾 Stores bookings in localStorage (persists on refresh).


---

🛠 Tech Stack

HTML5 & CSS3 – Structure & layout

⚙ Installation & Setup

1. Clone the repository:

git clone https://github.com/Naiya-Agarwal/parking-application-form.git
cd parking-application-form


2. Install dependencies:

npm install


3. Start the development server:

npm start


4. Open the app in your browser:

http://localhost:3000
